町田商店本巣店 掃除チェック（GitHub Pages 版 v6.4.2）
=================================================

■ GitHub Pages に置く（最初の1回だけ・無料・画面にロゴは出ません）
iPadのSafariで github.com を開いてログインして進めます。

1. 置き場所（リポジトリ）を作る
   右上の「＋」→「New repository」
   ・Repository name：soji-check（半角。好きな名前でOK。これがURLの一部になります）
   ・「Public」を選ぶ（無料で公開するにはPublicが必要。見られるのはアプリの作りだけで、記録や写真は見られません）
   ・「Add a README file」にチェック
   →「Create repository」

2. ファイルを入れる
   「Add file」→「Upload files」→「choose your files」
   → このzipを「ファイル」アプリで解凍しておき、中の7つのファイルを全部選ぶ
     （index.html / sw.js / manifest.webmanifest / README.txt / icon-180.png / icon-192.png / icon-512.png）
   → いちばん下の「Commit changes」

3. 公開する
   リポジトリの「Settings」→ 左メニュー「Pages」
   → Source：「Deploy from a branch」、Branch：「main」「/ (root)」→「Save」
   1〜2分待つと、上に「Your site is live at https://（ユーザー名）.github.io/soji-check/」と出ます。これがアプリのURLです。

4. iPadのホーム画面に追加（下の「移し替え」も参照）
   SafariでそのURLを開く → 共有ボタン（□に↑）→「ホーム画面に追加」

■ 今までのアプリ（Netlify版）から記録を移す
  1. 今までのアイコンから開く →「管理」→「バックアップを作成」→「ファイルに保存」
  2. 新しいURLをSafariで開いて「ホーム画面に追加」
  3. 新しいアイコンから開く →「管理」→「バックアップから復元」→ さっきのファイルを選ぶ
     （新しいアプリの暗証番号は、最初の番号に戻っています）
  4. 記録が入ったのを確認してから、古いアイコンを削除
  ※ ビフォー・アフター写真はバックアップに入らないので移りません。

■ アプリを新しくするとき
  リポジトリを開く →「Add file」→「Upload files」→ 新しいファイルを選ぶ（同じ名前は上書きされます）
  →「Commit changes」。1〜2分で反映され、アプリを開き直すと新しい版になります。
  ※ URLは変わらないので、記録はそのまま残ります。

■ アイコンを変えたいとき
  icon-180.png / icon-192.png / icon-512.png を、新しい画像（同じ名前・正方形）にして上の手順でアップロード。
  そのあとホーム画面に追加し直します（バックアップ→復元を忘れずに）。

■ ほかの人のスマホでも見たいとき
同じURLをLINEなどで送れば、その人のiPhoneでも開けます（ホーム画面にも追加できます）。
ただしデータは端末ごとに別々です。iPadが本番の記録用、スマホは「やり方を見る用」になります。
スマホにも同じ内容を入れたい場合は、iPadで「バックアップを作成」したファイルを送り、
相手の端末で「バックアップから復元」してください。


■ 毎日の使い方（誰でも・暗証番号なし）
・「完了日」の欄をタップ →「やった人を選ぶ」（複数選べます）→ 日付を選ぶ（最初は今日）
  → 下の赤い枠「○/○・名前 で登録」を押す
・日付を間違えたら、もう一度開いて正しい日を選んで登録するだけで入れ替わります。
・カレンダーの緑の丸は「過去の実施日」。押すと、だれがやったかが出ます（取り消しもここから）。
・途中までのときは、項目を開いて「メモを書く」→「まだ終わっていない（途中）」をオン。
  一覧に【途中】と出て、未完了のままになります。
・「期限」の列が、いつまでにやればいいかです。リセット日の前日までです。
・「未完了だけ表示」を押すと残りだけになり、もう一度押す（すべて表示）と全部に戻ります。
・項目名をタップすると、やり方（手順・写真・動画）が見られます。
・項目を開くと「これまでの記録」で、過去にいつ・だれがやったか確認できます。


■ 自動リセットについて
・リセット日になると、完了のチェックが自動で外れて、新しい期間が始まります。
・過去の記録は消えません（「これまでの記録」に残ります）。
・初期設定：ウィークリー＝毎週土曜、2ウィーク＝第1・第3土曜、月1＝第1土曜。
  つまり金曜までに終わらせる形です。
・変更したいときは「管理」→「設定」→「リセットのタイミング」。


■ 上の2つのボタン
・「編集」…項目の追加・並び替え・やり方（手順・写真・動画）の登録。もう一度押すと終わります。
・「管理」…設定（スタッフ名、リセットのタイミング、見た目、言葉の書き換え、バックアップ、暗証番号）。
・どちらも暗証番号が必要です（一度入れたら10分間は聞かれません）。

■ 見た目や言葉を変えたいとき
「管理」→「見た目」で、背景（白／黒）・メインの色・文字の大きさ・一覧の列を変えられます。
「管理」→「文字の書き換え」で、列の名前やボタンの言葉などを自由に変えられます。

■ リセットのタイミングを日付で決める
「管理」→「リセットのタイミング」で、ウィークリー・2ウィーク・月1それぞれを
「曜日で指定」（今まで通り）か「日付で指定」（毎月◯日・◯日…）に切り替えられます。
日付は複数選べます。毎月くり返されます（31日など無い月はその月だけスキップ）。

■ アプリのURLをすぐ確認したいとき
「管理」→「ホーム画面のアイコン」の上に、このアプリのURLが表示されています。
タップするとSafariで開き、そのまま「ホーム画面に追加」できます。
新しいアイコンを試すときなどに便利です。

■ 使い方の動画（アプリ全体）
アプリを開くと出てくる「使い方」ボタンから、いつでも動画を見られます。
動画の追加・削除・並び替え・タイトル変更は「使い方」→「編集」（暗証番号が必要）から。
（管理」→「使い方の動画」からも同じ画面に入れます）
複数の動画を入れられます。動画の長さ制限はありません（iPadの空き容量が上限です）。
バックアップ・復元の対象にも含まれます。

■ ホーム画面のアイコンを変えたいとき
「管理」→「ホーム画面のアイコン」→「画像を選ぶ」。アイコンの下の名前も変えられます。
※ すでにホーム画面にあるアイコンは変わりません。追加し直す必要があります。
  1. 今のアプリで「バックアップを作成」して保存
  2. SafariでURLを開き、「管理」→ 同じ画像を選ぶ（Safariとアプリは中身が別のため）
  3. 共有ボタン →「ホーム画面に追加」
  4. 新しいアイコンから開いて「バックアップから復元」
  5. 記録が入ったのを確認してから、古いアイコンを削除（先に消すと記録も消えます）

■ やり方（手順・写真・動画）の登録
「編集」→ 項目名をタップ →「この項目を編集」→「＋ ステップを追加」
文章を書き、「＋ 写真・動画を追加」でその場で撮影するか、写真ライブラリから選びます。
動画の長さ制限はありません。iPadの空き容量が上限です（「設定」で使用量を確認できます）。


■ バックアップ（保険。取らなくてもデータは消えません）
保存する：「管理」→「設定」→「バックアップを作成」→「ファイルに保存」→ iCloud Drive など
元に戻す：「管理」→「設定」→「バックアップから復元」→ .seisou ファイルを選ぶ
※ 項目・完了日・やった人・メモ・スタッフ名・写真・動画がすべて入ります。
※ iPadを買い替えるときも、このファイルがあれば新しい端末にそのまま移せます。


■ v6.4.0 で変わったこと
・項目の画面の「やり方」の上に「ビフォー・アフター写真」を追加しました。
  「＋ 撮る・選ぶ」でその場で撮影するか、写真ライブラリから選びます（ビフォー・アフター各6枚まで）。
  写真は容量を抑えるため、自動で小さく（長い辺1280px）して保存します。
・写真はリセットごとに整理されます。
    今回の分 … 撮ったり消したりできる
    前回の分 … 「前回の写真」を開くと見られる（見るだけ）
    それより前 … 次のリセットで自動的に消える
  ウィークリーの項目なら「1週間前の分」だけが残ります（2ウィーク・月1は、その1回前の分）。
  ※ ビフォー・アフター写真はバックアップには含まれません（一時的な記録のため）。
・項目を編集する画面の「保存する」を、画面の一番上にも付けました。
・Larkなど、ほかのアプリの中で開いたときは、画面の上に案内が出ます。
・新しい版を置くと、アプリを開き直したとき（画面に戻ったとき）に自動で新しい版に切り替わります。


■ Larkから開いている場合（大事）
Larkでリンクを押すと、Larkの中のブラウザで開きます。ここはSafariともホーム画面のアプリとも
「中身（記録・写真）が別」の場所です。Larkの中で記録しても、ホーム画面のアプリには入りません。
また、Larkの中からは「ホーム画面に追加」もできません。
  1. Larkで開いた画面の右上「…」→「ブラウザで開く（Safariで開く）」
  2. Safariの共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
  3. 以後は、Larkのリンクではなく、ホーム画面のアイコンから開く
すでにLarkの中で記録してしまった内容を移したいときは、Larkの中で「管理」→「バックアップを作成」→
「ファイルに保存」し、ホーム画面のアプリで「バックアップから復元」してください。


■ iPadのホーム画面で変更が反映されないとき
【アプリの中身（新しい版）が反映されない】
  ・ホーム画面のアプリを完全に閉じて（下から上にスワイプしてアプリ一覧から上に払う）、開き直してください。
  ・v6.4.0 からは、開き直すと自動で新しい版に切り替わります。「管理」→ いちばん下のバージョンで確認できます。
  【アイコン・アイコンの名前が変わらない】
  ・iPadは、ホーム画面に追加した「その瞬間」のアイコンと名前を覚えています。後から変えても、
    すでにあるアイコンは変わりません。これはiPadの仕組みで、アプリ側では変えられません。
  ・アイコンを確実に変える方法：アイコン画像そのものを差し替えて置き直すのが一番確実です。
    icon-180.png / icon-192.png / icon-512.png を新しい画像（同じ名前・正方形）に差し替えて
    GitHubにアップロードし直し、ホーム画面に追加し直してください。
  ・ホーム画面のアプリを消すと、そのアプリの記録も一緒に消えます。追加し直す前に必ず
    「バックアップを作成」→ 新しいアイコンで「バックアップから復元」→ 確認してから古いアイコンを削除、の順で。
